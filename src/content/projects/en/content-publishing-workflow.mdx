## Problem

The team needed a faster publishing workflow without scattering small content updates across too many code files.

## Approach

- Used MDX as the primary source for case study content.
- Kept metadata explicit so cards, SEO, and sitemap data could reuse the same source.
- Standardized the folder structure to make new entries predictable.

## Impact

New content became easier to ship, preview stayed closer to production, and the bilingual routing setup stayed maintainable.
